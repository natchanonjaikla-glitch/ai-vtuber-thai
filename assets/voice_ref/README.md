# โฟลเดอร์เสียงอ้างอิงสำหรับ F5-TTS-THAI (voice cloning)

ใส่ 2 ไฟล์นี้ถ้าจะใช้ `/voice f5`:

| ไฟล์ | รายละเอียด |
|------|-----------|
| `ref.wav` | เสียงพูดภาษาไทยชัด ๆ ความยาว **8–12 วินาที** · mono · 24000 Hz (16000 ก็ได้) · ไม่มีเสียงรบกวน/ดนตรี |
| `ref.txt` | ข้อความ (ภาษาไทย) ที่พูดใน `ref.wav` แบบเป๊ะทุกคำ |

ตัวอย่าง `ref.txt`:
```
สวัสดีค่ะ วันนี้อากาศดีมากเลยนะคะ เราอยากชวนทุกคนมาพูดคุยกันแบบสบาย ๆ
```

เคล็ดลับ:
- เสียงใน `ref.wav` จะกลายเป็น "เสียงตัวละคร" ของ VTuber
- อัดด้วยไมค์ปกติก็ได้ พูดโทนที่อยากให้ตัวละครเป็น (สดใส/นุ่มนวล/ฯลฯ)
- แปลงไฟล์เป็น wav 24k mono:  `ffmpeg -i input.mp3 -ar 24000 -ac 1 ref.wav`

> ไฟล์ `.wav` ในโฟลเดอร์นี้ถูก gitignore ไว้ (ไม่ commit เข้า repo)
